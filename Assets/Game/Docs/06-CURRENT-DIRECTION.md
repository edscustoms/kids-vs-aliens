## Story principles

- Good story, revealed progressively
- Do not reveal the full alien conflict at once
- Game should be genuinely difficult
- Repeated play + upgrades should make difficult content more manageable
- Player earns power by spending time and learning
- More story revelation → more twists / stranger context
- More progression → more meaningful abilities/upgrades

Current hidden truth direction:
- protagonist was kidnapped by aliens
- alien factions are in conflict
- a rebel alien is secretly helping
- some mysterious “enemy” beaming/teleportation is actually rebel intervention
- player initially helps the rebellion without understanding it

## Marketing readiness principle

Do not wait for the whole game before creating social content.

Start serious TikTok / Reels / Shorts activity once we can repeatedly capture **10–20 second fragments that look like a real desirable game**:
- colorful combat
- satisfying VFX
- enemy interactions
- grenades
- rifle
- crazy upgrade combinations
- story/mystery moments

Gameplay and marketing moments should reinforce each other.
